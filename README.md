# 구보공영(주) 현장 안전 관리 시스템

구보공영(주)의 10개 현장 근로자를 위한 안전 관리 웹 애플리케이션입니다.

## 주요 기능

### 1. 작업중지권 행사 🛑
- 위험 상황 즉시 신고
- 실시간 안전관리팀 통보
- 작업중지 승인/재개 관리

### 2. 건의사항 제출 💡
- 현장 개선사항 제안
- 안전/환경/작업조건 등 분류별 관리
- 검토 및 피드백 시스템

### 3. 관리자 대시보드 📊
- 전체 현장 통합 관리
- 작업중지 및 건의사항 현황 조회
- 상태별 처리 및 승인 시스템

## 포함된 현장

1. 용인시 에코타운 조성 민자사업 현장
2. 운정3지구A-8BL민간임대주택신축공사
3. 장위6구역 주택재개발 정비사업파트 신축공사
4. 용인 은화삼지구 A1BL 공동주택 신축공사
5. 학익3구역 주택재개발정비사업
6. 송도 역세권 2블럭 신축공사
7. 양주역세권5 공동주택 신축공사
8. 성수장미아파트
9. 부천대장 A5 6BL공공주택
10. 수표구역 도시정비형 재개발사업

## 기술 스택

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: CSS3 (Custom)
- **Storage**: LocalStorage

## 시작하기

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 빌드
```bash
npm run build
```

### 프리뷰
```bash
npm run preview
```
